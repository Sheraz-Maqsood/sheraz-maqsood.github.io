# Sheraz Maqsood — Portfolio

Personal portfolio for **Malik Sheraz Maqsood Ahmed** — Principal Full-Stack & GIS Engineer.
Hosted at [sheraz.is-a.dev](https://sheraz.is-a.dev) (GitHub Pages, served from the root of `main`).

## Where things live

| Edit this | To change |
|---|---|
| `index.html` | the homepage content |
| `scripts/projects-data.mjs` | every project dossier (titles, copy, screenshots, videos, PDFs) |
| `scripts/templates/project.html` | the layout shared by all dossier pages |
| `assets/css/site.css` | all styles (one file for every page) |
| `assets/js/components.js` | the header / navigation and the CV link |
| `assets/js/main.js` | homepage + shared behaviour (tabs, reveal, section pager, sound…) |
| `assets/js/project.js` | dossier behaviour (video, screenshot lightbox, PDF viewer) |
| `assets/js/living-network.js` | the "Choose a system." project explorer |
| `404.html` | the not-found page |

Generated by the build — **don't edit by hand**: `*.min.css`, `*.min.js`, `projects/<id>/index.html`,
`sitemap.xml`, `scripts/.build-state.json`, and the header block between `<!--header-->` markers.

Other folders: `assets/sheraz/` photos, `assets/projects/<id>/` screenshots, videos, PDFs and the
social card `og.jpg`, `assets/files/` the CV (compressed copy; the original PDF stays in the root).
Kept for reference, not loaded by any page: `assets/css/styles.css`, `refresh.css`,
`living-network.css` (the pre-merge stylesheets) and `assets/legacy/` (the old JS-rendered
dossier, hidden from search engines).

## Build

```bash
npm ci            # once
npm run build     # after any change
```

The build minifies CSS/JS with content-hash cache keys, writes the header into every page,
generates one static, crawlable page per project at `/projects/<id>/` (own title, description,
canonical URL, Open Graph card and structured data), and refreshes `sitemap.xml` — a page's
`lastmod` only changes when that page's HTML changes.

You don't have to remember it: `.github/workflows/build.yml` runs the same build on every push
to `main` and commits the result (`[skip ci]`), so the live site can't serve a stale build.

Old dossier links (`project.html?id=lte`) redirect to the new pages (`/projects/lte/`).

## Security & privacy

- Content-Security-Policy and referrer policy are set with `<meta>` tags (GitHub Pages can't send
  headers). Only same-origin scripts run; the contact form may only post to FormSubmit.
- No inline event handlers or third-party scripts; fonts, icons and media are self-hosted.
- The contact form has a honeypot field and a time check that silently drops instant bot posts.
  Tip: in FormSubmit you can replace the e-mail address in the form `action` with the random
  alias FormSubmit gives you after the first submission, so the address isn't in the page source.

## Tech

Vanilla HTML/CSS/JS — no framework, no runtime server. esbuild for minification.
